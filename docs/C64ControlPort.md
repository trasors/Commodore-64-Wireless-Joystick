# Commodore 64 Control Port Mapping

ATTiny 1634 to C64 control port mapping

|Pin  |Function |Control Port 1|Control Port 2|
|-----|---------|------|------|
|1    |Up       |PA3   |PC4   |
|2    |Down     |PA2   |PC2   |
|3    |Left     |PA1   |PC0   |
|4    |Right    |PA0   |PB3   |
|5    |Pot A    |      |      |
|6    |Button   |PA4   |PC5   |
|7    |+5V 100Ma|      |      |
|8    |GND      |      |      |
|9    |Pot B    |      |      |

Pxx refer to ATtiny1634 pins
